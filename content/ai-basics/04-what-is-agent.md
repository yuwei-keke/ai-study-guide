# 什么是 AI Agent

## 一句话解释

AI Agent（智能体）是一个能**自主完成任务**的 AI——它不只是回答你的问题，还能自己规划步骤、使用工具、完成复杂任务。

## 小白类比

### 普通 AI（如 ChatGPT 对话）= 一个很聪明的客服

你问一句，它答一句。你不问，它就不动。每次对话都是独立的，它不会主动做事。

### AI Agent = 一个有手有脚的助手

你给它一个目标（比如"帮我做一个网站"），它会：

1. **分析任务**：做网站需要哪些步骤？
2. **制定计划**：先做什么，后做什么
3. **执行操作**：自己写代码、创建文件、运行测试
4. **检查结果**：看看有没有错误，如果有就自己修
5. **交付成果**：把完成的网站给你

**核心区别**：普通 AI 是"你问我答"，AI Agent 是"你说目标，它自己干"。

## 通俗解释

AI Agent 有几个关键特征：

### 1. 能使用工具

普通 AI 只能生成文字。AI Agent 可以：
- 读写文件
- 运行命令
- 搜索网页
- 调用 API
- 操作数据库

就像一个人不光能说话，还能动手干活。

### 2. 能自主规划

你不需要告诉它每一步怎么做。你说"帮我做一个个人博客"，它会自己：
- 分析需要什么技术
- 创建项目结构
- 写代码
- 测试
- 部署

### 3. 能循环迭代

如果第一步做的有问题，它会：
- 发现错误
- 分析原因
- 修复问题
- 重新检查

这个过程会自动重复，直到任务完成。

### 4. 有记忆

在一次任务中，Agent 能记住之前做了什么，不会重复劳动。

## 实际例子

### 例子 1：用 Claude Code 做一个网页

```
你说：帮我做一个待办事项网页

Claude Code 会：
1. 创建 index.html 文件
2. 写 HTML 结构
3. 写 CSS 样式
4. 写 JavaScript 逻辑
5. 运行看看有没有报错
6. 如果有错，自动修复
7. 告诉你：做好了，用浏览器打开 index.html 就能用
```

### 例子 2：用 Codex 分析代码

```
你说：分析一下这个项目的代码质量

Codex 会：
1. 读取项目的所有文件
2. 分析代码结构
3. 找出潜在问题
4. 给出改进建议
5. 如果你同意，它还能直接帮你改
```

### 例子 3：用 Cursor 写功能

```
你说：给这个网页加一个暗色模式

Cursor 会：
1. 分析现有代码
2. 找到需要修改的文件
3. 添加暗色模式的 CSS
4. 添加切换按钮的逻辑
5. 测试切换是否正常
```

## 适合做什么

AI Agent 特别适合**有明确目标、需要多步骤完成**的任务：

- ✅ **项目开发**：从零开始做一个完整的项目
- ✅ **代码重构**：整理和优化已有代码
- ✅ **Bug 修复**：找到并修复代码中的错误
- ✅ **文档生成**：自动为项目生成文档
- ✅ **数据分析**：处理和分析大量数据
- ✅ **自动化任务**：定时执行重复性工作

## 不适合做什么

- ❌ **需要人类判断的决策**：Agent 不知道你的审美偏好
- ❌ **需要实时交互的任务**：它不能代替你跟人聊天
- ❌ **创意工作**：它能生成内容，但真正的创意还是需要你
- ❌ **需要专业知识验证的领域**：医疗、法律等

## 主流 AI Agent 工具

| 工具 | 适合场景 | 特点 |
|------|---------|------|
| Claude Code | 项目开发、代码编写 | 在终端中运行，适合开发者 |
| Codex | 代码分析、生成 | OpenAI 出品，擅长代码 |
| Cursor | 日常编程辅助 | 基于 VS Code，上手容易 |
| Trae | 快速原型开发 | 字节出品，中文友好 |
| Windsurf | 全栈开发 | 功能全面 |

## 关键概念

- **工具调用（Tool Use）**：Agent 能使用的工具，如读文件、运行命令
- **循环（Loop）**：Agent 自动重复执行-检查-修复的过程
- **上下文（Context）**：Agent 在一次任务中能记住的信息量
- **提示词（Prompt）**：你给 Agent 的指令，写得好 Agent 就干得好
