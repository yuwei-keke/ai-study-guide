# AI 编程工具对比

## 一句话解释

Cursor、Windsurf、Claude Code、GitHub Copilot 是目前最流行的 AI 编程工具，它们能帮你自动写代码。

## 小白类比

传统编程就像自己动手做饭，从买菜到切菜到炒菜全自己来。AI 编程工具就像有了一个厨房助手——你告诉它想做什么菜，它帮你切菜、配料，你只需要最后把关味道。

## 通俗解释

**Cursor**
- 基于 VS Code 改造的 AI 编程编辑器
- 特色：对话式编程，能理解整个项目上下文
- 适合：有一定编程基础的开发者
- 价格：免费版有限额，Pro 版 $20/月

**Windsurf（原 Codeium）**
- 另一个 AI 编程编辑器，和 Cursor 类似
- 特色：自动补全更流畅，免费额度更多
- 适合：预算有限的学生
- 价格：免费版功能较多

**Claude Code**
- Anthropic 官方的 AI 编程助手，命令行工具
- 特色：能直接操作文件、运行命令、管理项目
- 适合：想用自然语言做完整项目的用户
- 价格：需要 Claude API 或 Claude Pro 订阅

**GitHub Copilot**
- 微软/GitHub 出品，集成在 VS Code 中
- 特色：代码补全能力强，实时提示
- 适合：日常写代码的开发者
- 价格：$10/月，学生免费

**AI 辅助的在线平台**
- Replit、Bolt.new、v0.dev 等
- 特色：在浏览器里就能写代码和预览
- 适合：不想装软件的初学者

## 实际例子

做一个待办事项网站：

| 工具 | 怎么用 |
|------|--------|
| Cursor | 在编辑器里对话："帮我创建一个待办事项网页" |
| Claude Code | 在终端输入："创建一个待办事项网站，支持添加、删除、标记完成" |
| GitHub Copilot | 写代码时自动提示补全，按 Tab 接受 |
| Replit | 在浏览器里描述需求，自动生成并运行 |

## 适合做什么

- **Cursor**：需要 AI 辅助写代码，但想用传统编辑器体验
- **Claude Code**：想用纯自然语言从零做完整项目
- **Copilot**：写代码时需要实时补全建议
- **Replit**：不想装任何软件，浏览器里直接开始

## 不适合做什么

- 不要指望 AI 工具能 100% 正确，生成的代码一定要检查
- 不要在不同工具之间频繁切换，先精通一个
- 不要用 AI 工具来抄袭作业（要用来学习）

## 关键概念

- **IDE（集成开发环境）**：写代码的软件，比如 VS Code、Cursor
- **命令行工具**：在终端里运行的工具，比如 Claude Code
- **代码补全**：AI 根据你已经写的代码，自动提示下一行
