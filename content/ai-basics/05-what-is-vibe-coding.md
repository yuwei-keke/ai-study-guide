# 什么是 Vibe Coding

## 一句话解释

Vibe Coding 就是"凭感觉编程"——你用自然语言告诉 AI 你想要什么，AI 帮你写代码，你只需要看结果对不对。

## 小白类比

想象你去餐厅点菜。你不需要知道菜是怎么炒的，只需要说"我要一份宫保鸡丁，少放辣椒"，厨师就会帮你做出来。Vibe Coding 就是这样——你说需求，AI 当厨师帮你写代码。

## 通俗解释

Vibe Coding 这个词是 Andrej Karpathy（前特斯拉 AI 总监）在 2025 年提出的。核心理念是：

**传统编程**：你需要学习编程语言 → 一行行写代码 → 调试错误 → 运行

**Vibe Coding**：你用中文描述需求 → AI 自动写代码 → 你看效果 → 告诉 AI 哪里要改

这意味着即使你完全不懂编程，也能做出自己的网站、工具、小程序。

**关键特点：**
1. 用自然语言（中文/英文）描述需求，不需要写代码
2. AI 负责生成代码，你只负责验收效果
3. 迭代速度快，几分钟就能做出一个原型
4. 适合快速验证想法，不适合对性能要求极高的场景

## 实际例子

你可以这样对 Claude Code 说：

> "帮我做一个个人简历网站，要有自我介绍、技能展示、项目经历三个板块，配色用蓝色系，要适配手机端"

Claude Code 就会自动帮你生成 HTML、CSS、JavaScript 代码，你打开浏览器就能看到效果。不满意的话，继续说"把背景色改成浅灰色"，它就会帮你改。

## 适合做什么

- 快速做一个网页原型或 MVP（最小可行产品）
- 把脑子里的想法快速变成可运行的 demo
- 学习编程——通过看 AI 生成的代码来理解编程逻辑
- 做个人工具、小网站、自动化脚本

## 不适合做什么

- 不适合做大型商业项目（代码质量不够稳定）
- 不适合完全不检查代码就直接用（AI 可能有 bug）
- 不适合用来应付需要手写代码的考试

## 关键概念

- **MVP（最小可行产品）**：用最少功能验证想法的版本
- **迭代**：不断修改完善的过程，Vibe Coding 的核心就是快速迭代
- **Prompt（提示词）**：你给 AI 的描述文字，写得越清楚效果越好
