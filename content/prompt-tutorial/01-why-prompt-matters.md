# 为什么提示词很重要

## 一句话解释

提示词就是你给 AI 的**指令**——写得好，AI 就能精准地完成你的任务；写得差，AI 就会给你一个不着边际的回答。

## 小白类比

想象你在餐厅点菜：

- **差的提示词**："给我来点吃的" → 服务员不知道你要什么，可能随便给你上
- **好的提示词**："我要一份宫保鸡丁，不要辣，米饭少一点" → 服务员知道你的确切需求

AI 就像那个服务员——你说得越清楚，它给你的结果就越好。

## 通俗解释

很多人第一次用 AI 时，会这样提问：

```
❌ 帮我做一个网站
```

AI 的反应：什么网站？做什么功能？用什么技术？给谁用？——它只能猜，猜出来的东西大概率不是你想要的。

正确的提问方式：

```
✅ 帮我做一个个人待办事项网页，要求：
- 用 HTML + CSS + JavaScript，不需要后端
- 能添加、删除、标记完成
- 界面简洁，浅色主题
- 数据保存在浏览器本地存储中
```

AI 的反应：清楚了！我来帮你做一个符合所有要求的待办事项网页。

## 实际例子

### 例子 1：写邮件

```
❌ 提示词：帮我写一封邮件
→ 结果：一封不知道发给谁、说什么的邮件

✅ 提示词：帮我写一封邮件给客户张经理，主题是项目延期通知。
原计划6月10日交付，现在需要延期到6月20日，原因是测试阶段发现了几个关键bug。
语气要诚恳但专业，不要太正式。
→ 结果：一封措辞得体、内容完整的邮件
```

### 例子 2：写代码

```
❌ 提示词：帮我写代码
→ 结果：不知道写什么语言、什么功能的代码

✅ 提示词：帮我用 Python 写一个脚本，功能是：
1. 读取 data.csv 文件
2. 统计每列的平均值
3. 把结果输出到 result.txt
→ 结果：一个可以直接运行的 Python 脚本
```

### 例子 3：让 Claude Code 做项目

```
❌ 提示词：帮我做一个网站
→ Claude Code 可能做出任何东西

✅ 提示词：帮我做一个个人作品集网站，要求：
【角色】你是一个前端开发专家
【背景】我是设计师，需要展示我的设计作品
【目标】做一个简洁、有设计感的作品集页面
【功能】
- 首页展示个人简介和代表作品
- 作品分类展示（UI设计、插画、摄影）
- 点击作品可以查看大图和详情
- 联系方式页面
【技术要求】
- 纯前端，不需要后端
- 响应式设计，手机端也能看
- 用 CSS Grid 或 Flexbox 布局
【不要做什么】
- 不要用任何框架（React、Vue等）
- 不要用付费的第三方服务
- 不要生成虚假的个人信息
→ Claude Code 能做出一个非常符合你需求的网站
```

## 好提示词的核心要素

一个好的提示词通常包含这些部分：

| 要素 | 说明 | 例子 |
|------|------|------|
| 角色 | 让 AI 扮演什么角色 | "你是一个前端开发专家" |
| 背景 | 任务的背景信息 | "我是一个零基础学生" |
| 目标 | 你想达成什么 | "做一个个人博客" |
| 功能需求 | 具体要做什么 | "能发布文章、评论" |
| 技术要求 | 用什么技术 | "用 HTML + CSS + JS" |
| 限制条件 | 不要做什么 | "不要用框架" |
| 验收标准 | 怎么算完成 | "手机端能正常显示" |

## 适合做什么

好的提示词能帮你：

- ✅ 让 AI 更准确地理解你的需求
- ✅ 减少来回修改的次数
- ✅ 得到更高质量的输出
- ✅ 避免 AI 做出你不想要的东西

## 不适合做什么

- ❌ 不能解决所有问题：有些任务 AI 确实做不好
- ❌ 不能一次到位：复杂任务需要分步骤、多轮对话
- ❌ 不能替代专业知识：你仍然需要判断 AI 的输出是否正确
