# 部署是什么意思

## 一句话解释

部署就是把你的网站从"自己电脑上能看"变成"全世界都能看"——把代码上传到服务器的过程。

## 小白类比

你在家里做了一桌好菜，只有自己能吃。部署就像把菜端到餐厅里——让所有顾客都能点餐品尝。

## 通俗解释

**本地开发 vs 部署上线：**

| | 本地 | 部署后 |
|---|------|--------|
| 地址 | localhost:3000 | yoursite.com |
| 谁能访问 | 只有你 | 全世界 |
| 数据 | 随时丢 | 持久保存 |
| 费用 | 免费 | 可能要花钱 |

**部署的方式：**

1. **静态网站部署**（HTML/CSS/JS）
   - 最简单，用 Vercel、Netlify、GitHub Pages
   - 免费，拖拽上传就行

2. **后端服务部署**
   - 需要一台服务器（云服务器）
   - 常用：阿里云、腾讯云、AWS

3. **容器化部署**
   - 用 Docker 打包后部署
   - 适合复杂项目

## 实际例子

用 Vercel 部署一个静态网站：

1. 把代码推到 GitHub
2. 在 Vercel 网站用 GitHub 登录
3. 选择你的仓库
4. 点击 Deploy
5. 1 分钟后，你的网站就有了一个 xxx.vercel.app 的地址

## 适合做什么

- 让项目被别人访问
- 展示你的作品集
- 做个人博客和网站

## 不适合做什么

- 不要在开发阶段就考虑部署
- 不要忘了设置环境变量
- 不要用生产服务器做测试

## 关键概念

- **域名**：网站的地址，如 google.com
- **CDN**：内容分发网络，让网站在全球都访问快
- **SSL/HTTPS**：加密传输，让网站更安全
