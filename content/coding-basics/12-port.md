# 端口是什么

## 一句话解释

端口就像一栋大楼的房间号——IP 地址是大楼地址，端口号是具体哪个房间，数据通过端口找到对应的程序。

## 小白类比

你住在一个小区（IP 地址），快递员要送快递给你。小区有很多栋楼、很多层、很多房间，端口号就是你的门牌号——有了门牌号，快递才能准确送到。

## 通俗解释

一台电脑上可以同时运行很多程序（网站、数据库、聊天软件），它们都需要通过网络收发数据。端口就是用来区分这些程序的。

**常见端口号：**
- **80**：HTTP 网站的默认端口
- **443**：HTTPS 安全网站的默认端口
- **3000**：前端开发常用
- **5173**：Vite 开发服务器默认端口
- **3306**：MySQL 数据库
- **27017**：MongoDB 数据库

**localhost:3000 的意思：**
- localhost = 你的电脑（127.0.0.1）
- :3000 = 第 3000 号端口
- 连起来 = 访问你电脑上第 3000 号端口对应的程序

## 实际例子

你在开发时可能同时运行：
- 前端开发服务器 → localhost:5173
- 后端 API 服务器 → localhost:3000
- 数据库 → localhost:3306

它们在同一台电脑上，但用不同端口区分，互不干扰。

## 适合做什么

- 区分同一台电脑上的不同服务
- 本地开发时指定程序运行在哪个端口

## 不适合做什么

- 不要随便占用被系统保留的端口（如 80、443）
- 不要忘记防火墙可能会阻止某些端口的访问

## 关键概念

- **端口号范围**：0-65535，其中 0-1023 是系统保留端口
- **端口冲突**：两个程序不能同时占用同一个端口
- **防火墙**：可以控制哪些端口允许外部访问
