# README 是什么

## 一句话解释

README 是项目的"说明书"——告诉别人这个项目是什么、怎么用、怎么参与贡献。

## 小白类比

你买了一个 IKEA 的家具，箱子里有一张说明书：这是什么家具、需要哪些工具、怎么组装。README 就是项目的说明书。

## 通俗解释

README 通常是一个 README.md 文件（Markdown 格式），放在项目根目录。GitHub 会自动把它显示在项目首页。

**一个好 README 应该包含：**
1. **项目名称和简介**：一句话说清楚这是什么
2. **功能列表**：这个项目能做什么
3. **安装方法**：怎么下载和运行
4. **使用方法**：怎么用
5. **贡献指南**：别人怎么参与贡献
6. **许可证**：代码的使用权限

## 实际例子

```markdown
# AI 学习指导书

一个面向零基础学生的 AI 学习知识库。

## 功能
- AI 基础知识学习
- 编程基础知识速查
- AI Agent 使用指南
- 提示词教程

## 安装
1. 克隆仓库：git clone https://xxx
2. 用浏览器打开 index.html

## 贡献
欢迎提交 Pull Request！

## 许可证
MIT License
```

## 适合做什么

- 让别人快速了解你的项目
- 降低项目的使用门槛
- 在 GitHub 上展示项目（第一印象很重要）

## 不适合做什么

- 不要写得太长太复杂（README 是入门文档，不是完整手册）
- 不要忘记更新 README（项目改了，说明也要跟着改）

## 关键概念

- **Markdown**：README 通常用 .md 格式编写
- **Badge**：README 顶部的小徽章，显示构建状态、版本号等
- **开源许可证**：规定别人怎么使用你的代码
