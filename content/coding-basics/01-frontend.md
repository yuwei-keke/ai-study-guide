# 前端是什么

## 一句话解释

前端就是你**在屏幕上能看到和操作的一切**——网页的布局、颜色、按钮、动画，都是前端。

## 小白类比

把一个网站想象成一家餐厅：

- **前端** = 餐厅的大厅、装修、菜单、桌椅 → 你看到和接触到的一切
- **后端** = 餐厅的厨房、厨师、食材仓库 → 你看不到，但没有它就没有菜上桌

当你打开淘宝，看到的商品图片、搜索框、购物车按钮——这些都是前端。当你点击"购买"，后台帮你扣款、生成订单——那是后端的事。

## 通俗解释

前端开发就是用代码来"装修"网页，让它好看、好用。主要用三种技术：

| 技术 | 作用 | 类比 |
|------|------|------|
| HTML | 搭建网页的骨架 | 房子的框架结构 |
| CSS | 给网页添加样式 | 装修（颜色、布局、字体） |
| JavaScript | 让网页有交互功能 | 家电（按钮能点、页面能动） |

举个例子，一个按钮：
- **HTML**：定义"这里有一个按钮，上面写着'提交'"
- **CSS**：定义"按钮是蓝色的，圆角的，鼠标放上去变亮"
- **JavaScript**：定义"点击按钮后，把表单数据发送给服务器"

## 实际例子

你每天都在跟前端打交道：

- 刷抖音 → 视频播放器的界面是前端
- 用微信小程序 → 小程序的界面是前端
- 浏览网页 → 网页的布局和样式是前端
- 手机 App → App 的界面也属于前端（移动端前端）

## 在 Claude Code / Codex 中什么时候会用到

几乎所有网页项目都涉及前端。当你让 Claude Code 帮你做网站时，它写的大部分代码都是前端代码：

```
你：帮我做一个个人博客网站

Claude Code 会创建：
- index.html      ← 前端：网页结构
- style.css       ← 前端：样式美化
- script.js       ← 前端：交互逻辑
```

## 常见错误

- **以为前端就是"做网页"**：前端不只是网页，小程序、App、桌面软件的界面都算
- **以为前端很简单**：现代前端工程化很复杂，但入门不难
- **分不清前端和后端**：记住——你能看到的 = 前端，看不到的 = 后端

## 示例代码

一个最简单的前端页面：

```html
<!DOCTYPE html>
<html>
<head>
  <title>我的第一个网页</title>
  <style>
    /* CSS：控制样式 */
    body { font-family: sans-serif; text-align: center; padding: 50px; }
    h1 { color: #4f46e5; }
    button { padding: 10px 20px; font-size: 16px; cursor: pointer; }
  </style>
</head>
<body>
  <!-- HTML：网页结构 -->
  <h1>你好，这是我的第一个网页！</h1>
  <p>点击下面的按钮试试</p>
  <button onclick="alert('你点击了按钮！')">点我</button>

  <script>
    // JavaScript：交互逻辑
    console.log('页面加载完成！');
  </script>
</body>
</html>
```

把上面的代码保存为 `index.html`，用浏览器打开，你就能看到一个简单的网页。
