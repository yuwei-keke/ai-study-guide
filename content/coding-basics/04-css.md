# CSS 是什么

## 一句话解释

CSS 是网页的"化妆师"——它负责让网页变得好看，控制颜色、字体、布局、动画等所有视觉效果。

## 小白类比

如果 HTML 是一个人的骨架，CSS 就是这个人的衣服、发型和妆容。同样的骨架，穿上不同的衣服就是完全不同的风格。

## 通俗解释

HTML 定义了网页有什么内容（标题、段落、图片），但默认长得很丑——黑色文字白色背景，所有东西从上往下堆叠。

CSS 就是用来美化这些内容的：

- **颜色**：文字颜色、背景颜色、边框颜色
- **字体**：字体大小、字体类型、行间距
- **布局**：元素排列方式、居中、分栏
- **间距**：元素之间的距离（margin、padding）
- **动画**：过渡效果、旋转、渐变
- **响应式**：在手机和电脑上显示不同的布局

**CSS 的三种写法：**
1. **内联样式**：直接写在 HTML 标签里（不推荐）
2. **内部样式**：写在 HTML 的 `<style>` 标签里
3. **外部样式**：单独的 .css 文件（推荐）

## 实际例子

```css
/* 让所有标题变成蓝色 */
h1 {
  color: #2563eb;
  font-size: 28px;
  text-align: center;
}

/* 让卡片有圆角和阴影 */
.card {
  background: white;
  border-radius: 12px;
  padding: 20px;
  box-shadow: 0 2px 8px rgba(0,0,0,0.1);
}

/* 手机上字体变小 */
@media (max-width: 768px) {
  h1 { font-size: 20px; }
}
```

## 适合做什么

- 控制网页的视觉样式
- 实现响应式设计（适配手机和电脑）
- 做动画和过渡效果
- 管理页面布局（Flexbox、Grid）

## 不适合做什么

- CSS 不能处理数据逻辑（那是 JavaScript 的事）
- CSS 不能动态生成内容
- CSS 复杂动画可能影响性能

## 关键概念

- **选择器**：告诉 CSS "你要美化哪个元素"（如 .class、#id）
- **盒模型**：每个元素都有内容、内边距、边框、外边距
- **Flexbox**：一种强大的布局方式，让元素灵活排列
- **响应式**：同一个网页在不同设备上显示不同的样式
