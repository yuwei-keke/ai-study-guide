# 终端 / 命令行是什么

## 一句话解释

终端就是"用文字操控电脑"——不用鼠标点来点去，直接输入命令让电脑执行。

## 小白类比

你平时用鼠标操作电脑就像用手语交流——直观但慢。终端就像直接说话——打字比手语快多了，而且能表达更复杂的指令。

## 通俗解释

终端（Terminal）是一个黑乎乎的窗口，你在里面输入文字命令，电脑执行后返回结果。

**为什么程序员爱用终端：**
- 比鼠标操作快很多
- 能执行复杂的批量操作
- 很多工具只有命令行版本
- 可以写脚本自动化重复操作

**常用命令：**
```bash
# 查看当前目录的文件
ls

# 进入某个目录
cd 文件夹名

# 回到上级目录
cd ..

# 创建文件夹
mkdir my-folder

# 删除文件
rm file.txt

# 查看当前路径
pwd

# 清屏
clear
```

## 实际例子

你想创建一个项目并启动开发服务器：

```bash
# 创建项目文件夹
mkdir my-project
cd my-project

# 初始化项目
npm init -y

# 安装依赖
npm install express

# 启动项目
node index.js
```

这一串命令用鼠标操作可能要好几分钟，用终端 30 秒搞定。

## 适合做什么

- 运行开发命令（npm、git 等）
- 批量操作文件
- 运行脚本和程序
- 管理服务器

## 不适合做什么

- 不要害怕它，命令不多，常用的就十几个
- 不要在终端里运行来路不明的命令
- 不要随意使用 rm -rf（删除所有文件）

## 关键概念

- **Shell**：终端里执行命令的程序（Bash、Zsh、PowerShell）
- **命令提示符**：终端里显示的前缀，告诉你当前在哪个目录
- **Tab 补全**：输入命令按 Tab 键自动补全，非常方便
