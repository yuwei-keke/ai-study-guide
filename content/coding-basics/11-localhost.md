# 本地运行与 localhost

## 一句话解释

localhost 就是你自己电脑的"内部地址"——用来在本地测试网站和程序，别人访问不了。

## 小白类比

localhost 就像你家的内线电话——只有家里人能打，外面的人打不进来。你用它在家里（自己电脑上）测试，等准备好了再部署到"公网"上让所有人访问。

## 通俗解释

当你开发一个网站时，你不会直接在真实的服务器上改代码（太危险了）。你需要先在自己电脑上运行和测试。

**localhost 是什么：**
- 一个特殊的网络地址，指向你自己的电脑
- IP 地址是 127.0.0.1
- 域名是 localhost
- 常配合端口号使用，如 localhost:3000

**本地运行的好处：**
1. 速度快——数据不用传输到远方服务器
2. 安全——只有你能看到
3. 免费——不消耗服务器资源
4. 方便调试——随时改代码随时看效果

## 实际例子

你用 Node.js 写了一个网站：

```bash
node server.js
# 输出：服务器运行在 http://localhost:3000
```

然后在浏览器打开 http://localhost:3000 就能看到你的网站了。但你的朋友在他们的电脑上输入这个地址是打不开的——因为 localhost 指向的是你自己的电脑。

想让朋友也能看到，就需要"部署"到公网上（后面的章节会讲）。

## 适合做什么

- 本地开发和测试网站
- 调试代码和排查问题
- 学习编程时运行示例代码

## 不适合做什么

- localhost 不是给别人访问的（那是部署的事）
- 不要把 localhost 地址发给别人说"看我的网站"

## 关键概念

- **127.0.0.1**：localhost 的 IP 地址，永远指向本机
- **端口**：同一台电脑上不同程序用不同的端口号区分
- **部署**：把本地程序发布到公网服务器上
