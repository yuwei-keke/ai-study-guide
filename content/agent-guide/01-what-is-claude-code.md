# Claude Code 是什么

## 一句话解释

Claude Code 是 Anthropic 推出的 AI 编程助手——它能理解你的项目、读写文件、运行命令，用自然语言就能帮你做项目。

## 小白类比

传统编程工具就像一个工具箱，你得自己选工具、自己动手。Claude Code 就像一个机器人助手——你告诉它"帮我做一个网站"，它就会自己打开工具箱、写代码、测试运行。

## 通俗解释

Claude Code 是一个运行在终端里的 AI Agent。它不仅能聊天，还能：

1. **读写文件**：帮你创建、编辑、删除文件
2. **运行命令**：帮你执行 npm install、git commit 等命令
3. **理解项目**：分析你的代码结构，理解项目上下文
4. **自主完成任务**：给它一个需求，它会分步骤自动完成

**和 ChatGPT 的区别：**
- ChatGPT 只能聊天，不能直接操作你的电脑
- Claude Code 能直接在你的项目里干活

**使用方式：**
- 命令行工具（终端里运行）
- VS Code 扩展
- JetBrains 扩展
- Web 版（claude.ai/code）

## 实际例子

你在终端里输入：

> "帮我做一个待办事项网页，要有添加、删除、标记完成功能"

Claude Code 会：
1. 创建 index.html 文件
2. 创建 style.css 文件
3. 创建 app.js 文件
4. 写好所有代码
5. 告诉你用浏览器打开就能看效果

## 适合做什么

- 用自然语言从零做项目
- 快速原型开发
- 学习编程（看 AI 怎么写代码）
- 自动化重复性开发任务

## 不适合做什么

- 不要完全不检查 AI 写的代码
- 不要用它处理高度机密的代码（数据会发送到云端）
- 不要期望一次就得到完美结果

## 关键概念

- **AI Agent**：能自主完成任务的 AI，不只是聊天
- **上下文窗口**：Claude Code 能"看到"的代码量
- **CLAUDE.md**：给 Claude Code 的项目说明文件
