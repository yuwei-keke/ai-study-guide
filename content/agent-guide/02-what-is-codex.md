# Codex 是什么

## 一句话解释

Codex 是 OpenAI 推出的 AI 编程智能体——它在云端沙盒中自主完成编程任务，支持代码生成、测试和调试。

## 小白类比

Claude Code 就像在你家里干活的助手（在你电脑上运行）。Codex 就像在远程办公室干活的助手（在云端运行），干完活把结果告诉你。

## 通俗解释

Codex 是 OpenAI 基于 GPT 系列模型开发的编程智能体。它集成在 ChatGPT 中。

**Codex 的特点：**
- **云端运行**：不需要在本地安装任何东西
- **沙盒环境**：在隔离的环境中运行代码，安全可控
- **自动测试**：写完代码会自动运行测试验证
- **支持多种语言**：Python、JavaScript、Go 等

**使用方式：**
1. 在 ChatGPT 中开启 Codex 功能
2. 用自然语言描述你的需求
3. Codex 在云端沙盒中写代码
4. 返回代码和运行结果

## 实际例子

你在 ChatGPT 中对 Codex 说：

> "用 Python 写一个贪吃蛇游戏"

Codex 会：
1. 在云端创建 Python 环境
2. 编写贪吃蛇游戏代码
3. 运行测试确保能玩
4. 把代码和演示链接发给你

## 适合做什么

- 快速生成代码片段和小工具
- 学习编程和算法
- 测试代码想法
- 不想装软件时快速体验编程

## 不适合做什么

- 不适合大型项目（没有本地文件系统集成）
- 依赖 OpenAI 服务，需要网络
- 复杂项目的上下文管理不如 Claude Code

## 关键概念

- **沙盒（Sandbox）**：隔离的运行环境，不会影响你的电脑
- **Codex CLI**：Codex 的命令行版本
- **代码生成**：AI 根据描述自动写代码
