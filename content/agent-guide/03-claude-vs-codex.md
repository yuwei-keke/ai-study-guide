# Claude Code 和 Codex 的区别

## 一句话解释

Claude Code 在本地运行，能直接操作你的项目文件；Codex 在云端运行，更安全但功能相对受限。

## 小白类比

Claude Code 就像一个在你家工作的装修工人——直接在你家干活，你能实时看到进度。Codex 就像一个在工厂做好家具再送货上门的——你只需要提需求，成品送到你手上。

## 通俗解释

| 对比项 | Claude Code | Codex |
|--------|------------|-------|
| 运行位置 | 本地电脑 | 云端沙盒 |
| 文件操作 | 直接读写本地文件 | 在沙盒中操作 |
| 实时交互 | 实时对话和调整 | 任务制，提交后等待 |
| 模型 | Claude 系列 | GPT 系列 |
| 使用方式 | 终端/VS Code | ChatGPT 内 |
| 适合场景 | 完整项目开发 | 代码片段和小工具 |
| 隐私 | 数据发送到 Anthropic | 数据发送到 OpenAI |
| 费用 | Claude Pro 订阅或 API | ChatGPT Plus 或 API |

**选择建议：**
- 想做完整项目 → Claude Code
- 快速生成代码片段 → Codex
- 在意本地文件操作 → Claude Code
- 不想装任何软件 → Codex

## 实际例子

同一个需求"做一个天气查询网页"：

**Claude Code 的做法：**
- 在你电脑上创建文件
- 你实时看到代码生成过程
- 可以随时说"把背景改成蓝色"
- 直接在浏览器打开看效果

**Codex 的做法：**
- 在云端写好代码
- 返回完整代码和运行结果
- 你复制代码到本地运行
- 想修改要重新提交需求

## 适合做什么

- 根据自己的需求选择合适的工具
- 两者可以配合使用

## 不适合做什么

- 不要纠结选哪个，先用起来
- 不要同时用两个工具做同一个任务

## 关键概念

- **本地 vs 云端**：代码在哪里运行
- **沙盒**：隔离的安全环境
- **交互模式**：实时对话 vs 任务制
